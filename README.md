# משימות הבית 🏠

אפליקציית ווב לניהול משימות בית משפחתיות: הוספת בני משפחה, הקצאת משימות עם קטגוריה, תאריך יעד, חזרתיות (יומי/שבועי/חודשי) ונקודות, וסימון משימות כבוצעו. הנתונים נשמרים מקומית בדפדפן (localStorage).

## הרצה מקומית

```bash
npm install
npm run dev
```

## בנייה לפרודקשן

```bash
npm run build
```

## טכנולוגיות

- React 19 + TypeScript
- Vite
- Tailwind CSS 4
- שמירה מקומית ב-`localStorage`, ללא צורך בשרת
